# Remotion Video Skill

## Propósito

Crear videos programáticos y composiciones de motion graphics después de una fase de investigación y planificación. La skill está pensada para agentes que trabajan dentro de Meridian Research Lab.

## Antes de construir

La skill debe recibir el objetivo del video, audiencia, idioma, duración, relación de aspecto, estilo visual, referencias, captions, audio, assets, licencia y llamada a la acción. Si falta una decisión importante, debe preguntar antes de generar código.

## Flujo

1. Investigar referencias actuales y guardar URLs verificables.
2. Escribir un brief con mensaje, audiencia y restricciones.
3. Dividir el video en escenas de una acción cada una.
4. Definir duración, composición, tipografía, colores, captions y audio.
5. Seleccionar las Agent Skills de Remotion necesarias.
6. Implementar la composición React.
7. Abrir un preview en Studio.
8. Renderizar un still o video.
9. Verificar dimensiones, duración, assets, textos, fuentes y licencia.
10. Entregar el artefacto con su evidencia de generación.

## Skills oficiales relacionadas

La documentación oficial de Remotion publica skills para buenas prácticas, creación, markup, Studio, render, captions, SaaS, interactividad, documentación, upgrades, multimedia y mapas.[1] Meridian las trata como dependencias externas que deben revisarse por versión y licencia.

## Contrato de salida

La skill debe producir la composición, los parámetros de entrada, un plan de escenas, los comandos de preview y render, la lista de assets, las fuentes investigadas y un informe de verificación.

## Límites

No debe inventar fuentes, copiar assets sin licencia, enviar videos a plataformas externas ni publicar contenido sin autorización. No debe afirmar que se renderizó un video si solo se generó el código.

## Prototipo inicial

La primera demo de Meridian tendrá 30 segundos, formato 16:9 y un estilo técnico oscuro. Mostrará el flujo `investigar -> planificar -> construir -> verificar` y dejará claro que es una visualización de investigación, no una demostración de un producto terminado.
