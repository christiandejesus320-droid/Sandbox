# Contribuir al Meridian Research Lab

Este repositorio acepta contribuciones centradas en investigación y prototipos de agentes autónomos. Las contribuciones deben explicar qué problema resuelven y qué evidencia respalda la propuesta.

## Tipos de contribución

Se aceptan documentos técnicos, comparaciones reproducibles, diagramas, evaluaciones, prototipos pequeños y correcciones de errores. Una propuesta puede ser teórica, pero debe declararlo con claridad.

## Antes de abrir un pull request

Describe el problema, el alcance, los supuestos, las fuentes consultadas y la forma de verificar el resultado. Si utilizas una API externa, documenta los límites, la atribución, el coste potencial y la forma de manejar credenciales sin incluir secretos.

## Revisión

Los cambios deben mantener la diferencia entre una capacidad implementada, una propuesta y una hipótesis. Las modificaciones que puedan publicar datos, ejecutar acciones externas o cambiar infraestructura requieren una revisión adicional.

## Alcance

La colaboración y los issues de investigación deben concentrarse en este repositorio. No se deben abrir pull requests artificiales ni generar actividad repetitiva sin una mejora real del proyecto.
