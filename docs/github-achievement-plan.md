# GitHub achievement plan

Este plan prioriza trabajo real dentro de Meridian Research Lab y no considera actividad artificial como una contribución de producto.

| Logro | Próximo paso posible | Dependencia |
|---|---|---|
| Pull Shark | Seguir fusionando mejoras sustantivas, no PRs vacíos. | El nivel superior requiere mucha más actividad y GitHub puede actualizarlo con retraso. |
| Pair Extraordinaire | Usar coautoría solo cuando exista colaboración real en un cambio. | Requiere otra persona que participe y acepte la colaboración. |
| Quickdraw | Ya conseguido. | No requiere más pruebas. |
| YOLO | Ya conseguido. | No requiere más pruebas. |
| Starstruck | Compartir el proyecto y conseguir estrellas de personas interesadas. | Depende de usuarios externos. No se puede fabricar. |
| Galaxy Brain | Responder preguntas útiles en Discussions y recibir aceptación. | Depende de la comunidad. No se puede automatizar honestamente. |
| Public Sponsor | Patrocinar a alguien mediante GitHub Sponsors. | Requiere una decisión y transacción económica explícitas. |

## Trabajo autorizado en esta fase

Las siguientes contribuciones son adecuadas para avanzar Pull Shark de manera legítima: mejorar el registro y clasificación de fuentes, añadir validación de dominios oficiales, documentar el contrato de un adaptador de búsqueda y añadir CI para ejecutar pruebas en cada pull request.

Cada cambio debe tener una razón técnica, pruebas y documentación. Las insignias son una consecuencia posible de la actividad; no son el contenido del repositorio.
